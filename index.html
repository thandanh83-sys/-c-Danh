PROMPT: TUYỆT TÁC KHÔNG GIAN ZEN THƯỢNG LƯU – WEB TRÌNH DIỄN KIẾN TRÚC & 3D TƯƠNG LAI

Mục tiêu tổng thể

Tạo một trang web Front-end thuần HTML + CSS + JavaScript dùng để:

  • Trình diễn mẫu hình ảnh nhà ở & không gian 3D tương lai
  • Truyền tải triết lý Zen Nhật Bản – Less is More
  • Mang cảm giác gaming clean – basic – hiện đại – đẹp – cute
  • Dễ mở rộng về sau cho AI / 3D / gallery nâng cao

Trang web không cần backend, mọi logic chạy ở client, code phải rõ ràng, tách lớp, đúng chức năng tồn tại của từng phần.

1. Triết lý thiết kế cốt lõi

1.1 Less is More – Zen Nhật Bản: Layout tối giản, nhiều khoảng thở, hình khối rõ ràng, chuyển động chậm có chủ đích.

1.2 Bảng màu: nền trắng ngà/be/xám rất sáng, điểm nhấn gỗ nhạt và xanh lá dịu, accent gaming cute xanh mint/pastel nhẹ, tránh màu gắt.

2. Cấu trúc trang (HTML Structure)

2.1 Header: logo chữ tối giản, menu icon nhỏ, sticky, thu gọn khi scroll.

2.2 Hero: tiêu đề lớn, mô tả “Zen – Japandi – Biophilic Future”, CTA “Explore the Space”, click scroll mượt.

2.3 Concept: grid card nhỏ với icon 🌿 🪵 ☀️ 🪨, hover nâng nhẹ, shadow mềm.

2.4 3D Vision: khung “3D Space”, mô tả cảm xúc, nút “Rotate View” đổi class, “Day/Night” đổi theme.

2.5 Materials: danh sách vật liệu scroll ngang mượt, icon minh họa.

2.6 Smart Living: toggle Light/Air/Curtain, ON/OFF đổi icon & màu dịu.

2.7 Gallery: grid ảnh, hover zoom nhẹ, click fullscreen overlay, ESC đóng.

3. Font & UI Style

Sans-serif tròn hiện đại, chữ nhẹ dễ đọc. Phong cách gaming clean, cute bo góc nhẹ, shadow mềm, glass effect hạn chế.

4. Animation & Interaction

Ít nhưng tinh, chậm vừa đủ: scroll reveal, hover micro-interaction, theme transition mượt.

5. Yêu cầu kỹ thuật

Chỉ dùng HTML/CSS/JS thuần. Code tách index.html, style.css, main.js. Mỗi logic JS có lý do tồn tại rõ ràng, ưu tiên readability.

6. Tinh thần khi sinh code

“Hãy viết code như đang thiết kế một ngôi nhà Zen: mỗi dòng đều có lý do tồn tại, không dư thừa, không phô diễn, nhưng đủ sâu để mở rộng tương lai.”

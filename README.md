# Zen Finance — Zen Auditor Edition

## Triết lý
**Quản trị bằng Logic — Thưởng thức bằng Tâm hồn.**

Zen Finance là hệ thống quản lý chi tiêu cá nhân theo hướng:
- Logic rõ ràng, không phán xét.
- Giao diện Zen · Gen Z · hiện đại.
- Rule-based auditor: phản hồi bằng dữ liệu thực tế.

## Nhân cách hệ thống (Zen Auditor)
- ✨ Chuyên gia tâm lý hành vi tài chính.
- 📊 Kiến trúc sư cấu trúc dòng tiền.
- 🪷 Triết gia Zen hiện đại.
- 🎮 Bạn đồng hành Gen Z tinh tế, không công kích.

## Tính năng chính
- Single-file app (`index.html`), mở trực tiếp là chạy.
- Lưu dữ liệu bền vững bằng `localStorage`.
- Quản lý thu nhập, chi tiêu, số dư, tỷ lệ tiết kiệm.
- Nhập chi tiêu bằng selector danh mục + **⭐ Mục khác** để thêm danh mục tự do.
- Ghi thời điểm bằng `datetime-local` (cho phép chỉnh sửa khi nhập muộn).
- Biểu đồ Doughnut/Bar realtime bằng Chart.js.
- Theme Light/Dark + màu chủ đạo tùy chỉnh.
- AI feedback rule-based:
  - ⚠️ Ví thấp
  - 🤨 Danh mục lệch
  - ✨ Cân bằng tốt
- Tùy chọn âm thanh phản hồi nhẹ.

## Chạy ứng dụng
Mở trực tiếp file `index.html` bằng trình duyệt hiện đại.
